# AutoLambada 🚗

Автомобильная площадка для покупки и продажи авто.

Пользователи могут просматривать автомобили, фильтровать их по параметрам, просматривать детали, читать новости и управлять личным кабинетом. Администраторы могут добавлять автомобили и загружать фотографии.

---

## 📄 Страницы сайта

* **Главная** — каталог автомобилей с фильтрами
* **Каталог** — просмотр автомобилей
* **Детали авто** — полная информация об автомобиле
* **Новости** — автомобильные новости и статьи
* **Профиль** — личный кабинет с избранным
* **Авторизация** — вход через email/телефон
* **Регистрация** — создание аккаунта
* **О нас** — информация о компании

---

## 🛠 Технологии

### Фронтенд

* **HTML5** — семантическая разметка
* **CSS3** — адаптивный дизайн, Grid, Flexbox
* **JavaScript** — динамическое взаимодействие с сервером, валидация форм, предпросмотр фото
* **FormData & Fetch API** — загрузка данных и изображений на сервер

### Бэкенд

* **ASP.NET Core 8** — REST API
* **Entity Framework Core** — работа с базой данных
* **JWT** — аутентификация пользователей
* **BCrypt** — хэширование паролей
* **Role-based Authorization** — защита административных функций

## 🔧 Запуск

### 1. Бэкенд

```bash
cd backend/AutoLambada.Api/
dotnet restore
dotnet run --no-launch-profile --verbosity quiet
```

> `--verbosity quiet` убирает лишние логи, чтобы вывод был минимальным.

* API запускается по умолчанию на `http://localhost:5195`

### 2. Фронтенд

```bash
cd frontend
npm install
npx http-server -c-1
```

* По умолчанию фронтенд доступен на `http://localhost:8080`

## ⚡ Особенности

* Регистрация и авторизация через email или телефон
* Проверка уникальности username, email и телефона при регистрации
* Загрузка до 5 фото на автомобиль с предпросмотром
* Фильтры по типу топлива, кузову и трансмиссии
* Адаптивный дизайн под мобильные устройства
